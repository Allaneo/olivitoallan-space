Salvo que se indique lo contrario, el trabajo original publicado por Allan Eloy Olivito está disponible bajo las siguientes condiciones:

### Software

El software y el código fuente originales se publican bajo la [Licencia MIT](https://opensource.org/license/mit). Se permite utilizarlos, modificarlos y distribuirlos, incluso con fines comerciales, siempre que se conserven los avisos de autoría y licencia.

### Artículos, datos y material técnico

Los artículos, la documentación de proyectos, los datasets, las figuras y los diagramas originales se publican bajo la [Licencia Creative Commons Atribución 4.0 Internacional](https://creativecommons.org/licenses/by/4.0/deed.es). Se permite compartirlos y adaptarlos para cualquier propósito, incluido el uso comercial, siempre que se otorgue el crédito correspondiente, se incluya un enlace a la licencia y se indiquen los cambios realizados.

> Allan Eloy Olivito, [olivitoallan.space](https://olivitoallan.space/)

### Excepciones

El material de terceros permanece sujeto a su licencia o aviso de derechos original. Las fotografías personales, los retratos, logotipos, marcas y demás elementos de identidad no están incluidos en las licencias anteriores salvo que se indique expresamente.

Si un proyecto o una publicación incluye su propio aviso de licencia, ese aviso específico tiene prioridad.
